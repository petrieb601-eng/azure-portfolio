Vaultlock

Authenticated AES-256-GCM encryption that runs entirely in your browser. Keys are derived from your passphrase with PBKDF2 (100k iterations, SHA-256).

your data never leaves this tab — no server, no network calls
algorithm AES-256-GCM · kdf PBKDF2 / SHA-256 / 100k · salt 16 bytes · iv 12 bytes
output format: base64( salt ‖ iv ‖ ciphertext+tag ) · built with the native Web Crypto API
